## 🚀 Sobre o projeto

A aplicação apresenta uma lista de personagens de Star Wars e permite ao usuário interagir com os personagens através de diferentes funcionalidades.

## ⚙️ Funcionalidades

- Listagem de personagens
- Busca de personagem por nome
- Sistema de "like"
- Remoção de personagens da lista
- Interação com o usuário através de mensagens
- Renderização dinâmica dos elementos utilizando Vue.js

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Vue.js
- Git
- GitHub

## 📚 Conceitos praticados

- Variáveis e constantes
- Arrays
- Objetos
- Funções
- Métodos de array
- `filter()`
- Estruturas condicionais
- Eventos
- Manipulação de dados
- Data binding com Vue.js
- Renderização dinâmica com `v-for`
- `v-model`
- Desenvolvimento de interface web
